# pve-meta

A permission-aware, structured (nested) key-value metadata store for Proxmox VE guests,
stored as human-readable sidecar files (YAML/TOML/JSON) in /etc/pve, with claims,
JSON-Schema-powered validation, and a Monaco editor tab integrated into the PVE web UI.

Knows nothing about operators. See ../VISION.pdf for the full vision & build plan.
